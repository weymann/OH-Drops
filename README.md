# openHAB Marketplace Drops

Repository storing openHAB jars / readme published on [openHAB Community Marketplace](https://community.openhab.org/c/marketplace/69).

Each folder contains one add-on with its documentation (`README.md`) and the built jar files (`drops`), one per supported openHAB version.

| Project | Description | Available versions |
| ------- | ----------- | ------------------ |
| [basic-profiles](basic-profiles) | Collection of useful profiles, e.g. debounce, round, threshold and time-weighted average. | OH 5.1 |
| [boschthermotechnology](boschthermotechnology) | Integrates Bosch and Buderus heating systems via the Bosch Thermotechnology PointT cloud. | OH 5.3 |
| [brightsky](brightsky) | Provides weather data from the German Weather Service (DWD) via the Bright Sky API. | OH 5.2 |
| [dirigera](dirigera) | Integrates the IKEA DIRIGERA gateway and its connected smart home devices, including Matter devices. | OH 5.2, OH 5.3 |
| [e3dc-rscp](e3dc-rscp) | Integrates E3/DC home power plants, including battery and wallboxes, via the RSCP interface. | OH 5.3 |
| [energycharts](energycharts) | Provides energy prices and renewable energy measurements from Fraunhofer ISE Energy-Charts. | OH 5.2 |
| [energychartsinfo](energychartsinfo) | Provides energy information and pricing from Fraunhofer ISE Energy-Charts together with a price forecast. | OH 5.2 |
| [energyforecast](energyforecast) | Provides an AI price forecast beyond EPEX day-ahead pricing via the Energy Forecast Service. | OH 5.2 |
| [geocoding](geocoding) | Transformation service translating GPS coordinates into addresses and vice versa using Nominatim. | OH 5.2 |
| [melcloud](melcloud) | Controls Mitsubishi air conditioners and heat pumps via MELCloud and MELCloud Home. | OH 5.3 |
| [mercedesme](mercedesme) | Provides access to Mercedes-Benz vehicles like the Mercedes Me smartphone app. | OH 5.2, OH 5.3 |
| [modbus/hager](modbus/hager) | Integrates the Hager Flow energy management system over Modbus. | OH 5.3 |
| [myskoda](myskoda) | Integrates Škoda vehicles via the MyŠkoda Public API, including charging and climatisation control. | OH 5.3 |
| [openweathermap](openweathermap) | Provides current weather, forecasts and further data from the OpenWeatherMap API. | OH 5.2 |
| [pegelonline](pegelonline) | Observes water levels of German rivers using data from the PEGELONLINE service of the WSV. | OH 5.3 |
| [sensorcommunity](sensorcommunity) | Integrates Sensor.Community sensors for particulate matter, temperature, humidity, noise and radiation. | OH 5.2 |
